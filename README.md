# Partners' Books

Partnership accounting for D&K Liquor & Whiskey: money accounts, partners, credit sales and customers, suppliers and stock, loans, funding approvals, and Word/PDF financial reports.

## Put it online with GitHub Pages

1. Sign in at github.com and create a **new repository** (for example `partners-books`). Choose **Public**, because free GitHub Pages needs a public repository.
2. Click **Add file > Upload files** and upload everything in this folder: `index.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` and this README. Click **Commit changes**.
3. Open the repository **Settings > Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then **Save**.
4. Wait one to two minutes. Your app is then at `https://YOUR-USERNAME.github.io/partners-books/`.
5. Open that link on your phone and use **Share > Add to Home Screen** (iPhone) or **Install app / Add to Home screen** (Android).

To update the app later, upload a new `index.html` to the same repository. GitHub replaces the old one.

## Important things to know

- **Your accounting data is not stored on GitHub.** It stays in the browser on each device. The code is public, but your figures are not, as long as you never upload backups to the repository.
- **No sync between devices.** A phone and a laptop each keep their own data. Use **Partners > Download backup** regularly and **Restore backup** to move data.
- **Keep the same web address.** A different address (for example a new username or repository name) starts with empty data. Restore from a backup if that happens.
- Clearing the browser's site data deletes the books. Back up first.
- Word and PDF exports load their tools from the internet, so use them while online.
- There are no logins. Anyone who opens the link on your device sees your books. For privacy, do not share the link on a shared phone.
